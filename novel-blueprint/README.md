# Novel Blueprint

A single developmental-editorial document: `NOVEL-BLUEPRINT.md`.

This is different from everything else in the repo — it's not filed lore, it's a
**synthesis and planning document** written by reading the entire repository
(story bible, all worldbuilding folders, the manuscript outline, and the drafted
chapters) and turning it into a draft-ready plan for Book One of the novel.

It contains, in order:

1. **Canon Audit** — which parts of the repository are the actual working canon
   (the Luminara/Damion Knightly/Order of the Emblematic thread the manuscript
   uses), which parts are fully-developed but unreconciled alternate worldbuilding
   sessions ("parked material"), and a list of the specific contradictions and
   gaps found between documents.
2. **Story Bible** — premise, theme, tone, genre, voice, comparable titles, core
   questions, stakes, and story promise.
3. **Structure** — a five-act structure mapped to the Hero's Journey, scoping
   Book One to Parts I–II of the existing outline.
4. **Major Characters** — full profiles for the eight characters carrying Book One.
5. **Chapter-by-Chapter Build** — Prologue + 34 chapters, each with purpose,
   conflict, setting, lore source, character development, ending hook, and
   word-count goal (~148,000-word target).
6. **Lore Integration, Pacing, and Revision Plan** — where worldbuilding surfaces
   without becoming exposition, a pacing map, and a running list of things to
   watch for while drafting.

It does not contain any manuscript prose — it's the roadmap, not the novel.
